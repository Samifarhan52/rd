# Reeya Digital / Riya Book Publication (रिया बुक पब्लिकेशन)

Official single-page web portal for **Riya Book Publication (Reeya Digital)** — India's premier manuscript typing and book digitization platform.

## 🚀 Live Features
- **Editorial Publishing Theme**: Crossword.in inspired aesthetic with royal wine (`#7B1113`), burnished gold (`#C59B27`), and warm paper (`#FAF7F2`) styling.
- **70% Salary Advance Guarantee**: Prominent highlights across Plan 1 (₹25,000), Plan 2 (₹30,000), and Plan 3 (₹35,000).
- **Interactive Calculator**: Real-time earnings and 70% advance calculation.
- **Book Catalog**: Curated literary showcase with filters.
- **Interactive Application Modal**: Direct application intake and verification.
- **Full-Resolution Poster Lightbox**: High-definition circular previews.

## 🌐 Deployment Instructions

### Deploy to Vercel
1. Import this repository in [Vercel](https://vercel.com).
2. Framework Preset: **Other** (Static HTML).
3. Root Directory: `./`
4. Click **Deploy** — your site will be live instantly with a free SSL certificate.

### Deploy to Hostinger
1. Log in to your Hostinger hPanel.
2. Go to **File Manager** -> `public_html`.
3. Upload `index.html`, `assets/`, and `.gitignore`.
4. Your website will be live immediately on your custom domain.
